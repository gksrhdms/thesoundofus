# 부딪힘소리 (The Sound of Us)

> 타인의 세계에 노크를 하고, 그 안으로 걸어 들어가는 일.

사람과 사람이 부딪힐 때 나는 소리를 기록하는 인터뷰 매거진입니다.
기획, 디자인, 개발을 혼자 했고, 프레임워크나 라이브러리 없이 HTML, CSS, 바닐라 JavaScript로 만들었습니다.

**Live** · https://gksrhdms.github.io/thesoundofus/

## 콘셉트

인터뷰는 질문하고 답하는 데서 끝나지 않고, 한 사람이라는 숲을 처음 탐험하는 일에 가깝다고 생각했습니다.
메인 페이지의 선언문은 한 줄로 읽히지 않습니다. 같은 문장을 조금씩 어긋나게 겹치고 기울여 놓아서, 여러 목소리가 동시에 들리는 것처럼 보이게 했습니다.
그 사이에 인터뷰라는 행위를 C 구조체(`Interview`, `ask()`, `answer()`)로 옮겨 적은 코드 조각을 섞어서, 정서적인 문장과 건조한 문법이 한 화면에서 부딪히게 했습니다.

## 인터랙션

**1. 밀려나는 선언문** (`index.html`)
선언문을 이루는 텍스트 조각 하나하나가 물리 객체처럼 움직입니다.
- 커서 반경 155px 안에 들어온 조각은 거리에 비례하는 힘으로 밀려납니다.
- 조각마다 원래 위치로 돌아가려는 스프링 힘과 감쇠가 걸려 있어서, 커서가 지나가면 천천히 제자리로 돌아옵니다.
- 조각끼리 겹치면 AABB 충돌 판정으로 서로 밀어냅니다.
- 터치 이벤트도 같은 방식으로 처리합니다.

**2. 사라지는 커서 궤적** (`index.html`)
커서가 지나간 길을 canvas에 연필 선처럼 남깁니다.
- 빠르게 움직이면 선이 가늘어지고, 천천히 움직이면 굵어집니다.
- 점들을 이차 베지어 곡선으로 이어 선을 부드럽게 만들었습니다.
- 1분 동안 선명하게 남아 있다가 45초에 걸쳐 흐려집니다. 오래된 구간은 불투명도별로 묶어서 그려 렌더링 비용을 줄였습니다.

**3. 밑줄 긋기** (`interviews/*.html`)
인터뷰 페이지에서는 마우스를 누른 채로 움직이면 형광펜 같은 선을 그을 수 있습니다. 읽는 사람이 마음에 남은 문장에 직접 표시하도록 하고 싶었습니다.

## 구조

```
index.html          메인: 선언문, 인터뷰 목록

style.css           공통 스타일
```
